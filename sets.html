Sets

Pick Unordered, Ordered or Linked list, then a function. Choose an example and press Next to run the code one line at a time. Every example starts from [1 4 5 7 9] (or 1 → 4 → 5 → 7 → 9 for the list) with size = 5.

counts (index < size) doesn't count being checked match just written ruled out by binary search

SetContains unordered

Is the number in the set? Check each used slot, left to right.

SetInsert unordered

If the number isn't already there, put it in the first empty slot, then add 1 to size.

SetDelete unordered

Find the number, copy the last value over it, then take 1 off size.

SetContains ordered

The array is sorted, so use binary search: look at the middle, then throw away the half the number can't be in.

SetInsert ordered

Binary search for where the number belongs, shift everything from there one place right, then drop it into the gap.

SetDelete ordered

Binary search for the number, then shift everything after it one place left to cover it.

SetContains linked list

Put your finger (curr) on the first node and follow the arrows until you find the number or hit NULL.

SetInsert linked list

Walk prev and curr to the right spot, make a new node, then change one arrow to hook it in. No shifting.

SetDelete linked list

Walk to the node, point the node before it past it, then free it. No shifting.
